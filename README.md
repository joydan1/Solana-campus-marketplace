3. About the Project
Solana Campus Marketplace is a decentralized platform designed to connect students who want to buy, sell, or trade goods and services within their campus community.
✨ Inspired by Jiji, it brings the convenience of an online marketplace to the student ecosystem but with a powerful twist: blockchain integration using Solana Pay.
🔑 Key Highlights
🛒 Peer-to-Peer Marketplace – Students can post, discover, and purchase items or services easily.


⚡ Blockchain Payments – Secure, fast, and transparent transactions powered by Solana Pay.


🎓 Campus-Centric – Focused on making buying & selling safer and more accessible within universities.


📱 User-Friendly Design – Simple, clean, and easy to navigate for everyday student use.


🔐 Trust & Transparency – Eliminates the risk of payment fraud through decentralized technology.


Our goal is to foster financial inclusion and innovation, while making everyday student transactions more efficient, safe, and fun.

6. Installation & Setup
Clone the repository:
git clone https://github.com/your-username/solana-campus-marketplace.git
cd solana-campus-marketplace

Install dependencies:
npm install

Start the development server:
node server.js

The backend will run on:
 👉 http://localhost:3000

7. API End Points
Listings Routes
GET /listings → fetch all listings


GET /listings/:id → fetch single listing


POST /listings → create a new listing


PUT /listings/:id → update a listing


DELETE /listings/:id → delete a listing


Users Routes
POST /users/register → create new user


POST /users/login → authenticate user
